# Online Shop — Front-end Prototype (B.Sc. Final Project)

Static UI prototype of the online store I built as my **B.Sc. final project** in Computer Engineering at **Malayer University** (2023).

> **Status:** archived, kept for reference and not maintained.

## Overview

Before implementing the store in Blazor, I designed its pages as a static, responsive Persian (RTL) prototype. These layouts were later rebuilt as Blazor components in the [back-end repository](https://github.com/Hosein-Bakhshayesh/Online-Shop-Back).

## Pages

| Page | File |
|---|---|
| Store home page | `Index.html` |
| Login and registration | `pages/Accounting.html` |
| Category product listing | `pages/CategoriesItem.html` |
| Product details | `pages/ProductDetail.html` |
| User panel | `pages/UserPanel.html` |
| Admin panel | `pages/Admin/Admin.html` |

## Tech stack

- HTML5, CSS3, JavaScript
- Bootstrap (RTL), jQuery, Font Awesome

## Running

No build step is needed: open `Index.html` in a browser.
